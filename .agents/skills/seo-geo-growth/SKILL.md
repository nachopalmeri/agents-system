# SEO/GEO/AEO Growth

## Purpose

Turn organic demand into qualified leads, signups or customers through high-intent SEO, GEO, AEO, local SEO and safe programmatic content.

## Default playbook

1. Research keywords and opportunities.
2. Prioritize commercial intent and low-competition wins.
3. Create useful landings, articles, comparisons, glossaries, tools or calculators.
4. Build authority with real backlinks and citations.
5. Use Search Console and GA4 to measure traffic and conversion.
6. Iterate monthly.

## Opportunity map

Classify opportunities by:

- Problem: “cómo gestionar stock”.
- Solution: “software para ferretería”.
- Industry/rubro: kioscos, pastelerías, clínicas, estudios contables.
- Geography: Argentina, provincia, ciudad, barrio if truly relevant.
- Comparison: X vs Y, alternativa a X, mejor herramienta para Z.
- JTBD: cobrar, gestionar, automatizar, ahorrar tiempo, conseguir clientes.
- FAQ: doubts, objections, price, setup, legality, timing.
- Glossary: terms users search before buying.
- Tool/calculator: utility that solves a concrete problem.

## Page types

### Money pages

Use for strong commercial intent and clear CTA.

### Supporting articles

Use for research intent that can internally link to money pages.

### Programmatic pages

Use only when each page has unique data or a real reason to exist.

### Local pages

Use only for real service areas, with local proof, NAP and business details.

### Tools/calculators

Use when a small utility can attract demand and demonstrate value.

## Quality gates

Before recommending publish/index:

- Real intent exists.
- Content is useful and differentiated.
- Page is not a doorway page.
- Page is not a keyword swap.
- Page includes examples, data, proof, local details or practical utility.
- CTA matches intent.
- Internal links are planned.
- Schema and metadata are appropriate.
- The page would be useful even without ranking.

## GEO/AEO checklist

- Ensure crawlable pages.
- Use clear entity/about pages.
- Add `llms.txt` when appropriate.
- Use structured headings.
- Add concise answer blocks.
- Add natural FAQs.
- Add authoritative citations where useful.
- Test target prompts in ChatGPT, Perplexity and Gemini.
- Track mentions, citations, sentiment and position.

## Backlink/citation strategy

Prefer:

- Google Business Profile.
- Real directories and citations.
- Local/industry PR.
- Partnerships.
- Customer case studies.
- Guest posts with editorial value.
- Community participation with genuine answers.

Avoid:

- Link farms.
- Paid spam links.
- Irrelevant directories.
- Comment spam.
- Private blog networks.

## MCP decision matrix

Optional MCPs:

- Ahrefs: keyword research, backlinks, competitor analysis.
- Semrush: competitive and keyword data.
- DataForSEO: SERP and keyword data.
- Google Search Console: queries, index coverage, sitemaps, URL inspection.
- GA4: organic conversion measurement.
- PageSpeed/CrUX: Core Web Vitals.
- Fetch/Jina/Firecrawl: read public pages, respecting ToS and robots.
- Google Sheets: backlog and reporting.

Rules:

- Read-only first.
- No hardcoded credentials.
- No scraping that violates ToS or robots.
- No paid actions or ad changes without explicit confirmation.
- Use `mcp_security.md` before adoption.

## Monthly operating system

Every month report:

- Pages shipped.
- Pages indexed.
- GSC clicks/impressions/CTR/position.
- GA4 conversions.
- Best and worst pages.
- New keyword opportunities.
- Backlinks/citations gained.
- AI search visibility tests.
- Next 30-day backlog.
