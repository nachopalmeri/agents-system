# Client Work

## Cuándo usar

- Cuando el usuario diga "armame una propuesta", "tengo un cliente", "pasame pricing", "me llegó feedback del cliente" o equivalente.
- Cuando el proyecto use el preset `client-work`.
- Cuando haya brief, alcance, iteraciones o discusión de fuera de scope.

## Archivos de referencia

- `pricing.md` para estructura comercial y categorías de pricing.
- `../../workflows/client_workflow.md` para el flujo operativo.

## Reglas

1. No inventar números si faltan precios; usar placeholders o pedir confirmación.
2. No cambiar scope sin registrarlo en `propuesta/`.
3. Todo feedback externo se registra antes de implementar.
4. Versionar propuestas; no sobrescribir `v1`, `v2`, etc.
5. Registrar decisiones difíciles de revertir en `tasks/decisions.md`.
6. Registrar shortcuts o compromisos técnicos en `tasks/tech-debt.md`.
