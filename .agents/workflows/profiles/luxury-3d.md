# Luxury-3D Profile

## Cuándo usar

- Marcas de lujo, moda, joyería, relojería, perfumería
- Showrooms virtuales de alta gama
- Real estate premium
- Automotriz (configuradores, lanzamientos)
- Experiencias de marca inmersivas

## Tono y estilo

- Oscuro con acentos de color (negro, dorado, plata, blanco hueso)
- Tipografía serif elegante (Cormorant Garamond, Playfair Display)
- Animaciones lentas, fluidas, tipo "hover"
- Espacio generoso: mucho whitespace
- Sonido ambiente opcional, sin UI ruidosa
- Transiciones: 600-800ms, easing suave (`cubic-bezier(0.65, 0, 0.35, 1)`)

## 3D

- Materiales: metalness + roughness realistas (Blender + Substance)
- Iluminación: IBL + tres luces sutiles
- Cámara: lenta, tipo docu, movimientos suaves
- Post-processing: bloom sutil, DOF para enfoque selectivo
- Loading: pantalla de carga con logo animado, no spinner

## Ejemplos de referencia

- Cartier: immersive garden con alcoves narrativos + sonido ambiente
- PorscheLab: 100/100 Lighthouse con 3D fotorealista
- Hermès: scroll storytelling con productos en foco

## Regla

Menos es más. Un objeto 3D perfecto vale más que diez objetos mediocres.
