# Portfolio-3D Profile

## Cuándo usar

- Portfolios de diseñadores, artistas, fotógrafos
- Agencias creativas mostrando su trabajo
- Showcases de productos o proyectos
- Landing de estudio de diseño/arquitectura
- Páginas personales con ambición visual

## Tono y estilo

- Depende del portafolio: clean / bold / experimental
- Tipografía: sans-serif moderna (Inter, Space Grotesk, Satoshi)
- Grid de proyectos interactivo
- Transiciones entre proyectos fluidas (morph, slide, fade)
- Light y dark mode toggle
- Load fast: los projects cargan lazy

## 3D

- Opcional: fondo 3D sutil, o proyecto destacado en 3D
- Scroll: trigger de aparición por proyecto
- Galería 3D: carrusel con thumbnails 3D (si aplica)
- Camera: orbit suave o look-at con scroll

## Estructura típica

- Hero con name/role + CTA
- Proyectos: grid + filtros
- About minimal
- Contact: form o link

## Regla

El portfolio es el producto. Cada proyecto debe cargar rápido y mostrar lo mejor primero.
