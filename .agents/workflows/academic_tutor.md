# Academic tutor routing

Use for teaching a concept, guided exercises, review or exam preparation. Load `skills-library/academic-tutor/SKILL.md` and its shared `workflows/learning_protocol.md`; select explain, practice or notes from the user's goal.

- A conceptual question can be answered from supplied context without opening the vault.
- Processing a class uses `skills/procesar-clase-vault/SKILL.md` and the vault's current study method.
- Writing or improving notes uses `skills/obsidian-vault/SKILL.md` and its approval rules. Do not create Atlas concepts, flashcards or MOC updates as a side effect.
- Project learning guides use `skills-library/project-learning-guide/SKILL.md`; keep their simple English and verified source links.

Resolve missing skill paths through `skills-library/INDEX.md`. Do not preload every tutor skill. Current course dates and exam scope come from verified material, never the historical Q1 calendar. Old routing is preserved in `archive/teaching/` for history only.
