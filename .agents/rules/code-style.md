# Reglas de Estilo de Código

## Generales
- Simplicidad primero: el código más simple que resuelva el problema
- Sin comentarios obvios: el código debe ser autoexplicativo
- Nombres descriptivos en inglés para variables y funciones
- Commits y mensajes al usuario en español

## JavaScript / TypeScript
- Preferir const sobre let, nunca var
- Arrow functions para callbacks
- Async/await sobre .then()
- No usar any en TypeScript sin justificación

## CSS
- Variables CSS para colores y espaciados repetidos
- Mobile-first por defecto
- Clases descriptivas, sin IDs para estilos

## HTML
- Semántico siempre: article, section, nav, main, header, footer
- Alt text en todas las imágenes
- Lang attribute en el html root
