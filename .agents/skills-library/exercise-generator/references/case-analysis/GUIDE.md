# Case Analysis

## Activación
- Cuando el estudiante pida ejercicios de Economía o Gestión
- Cuando el tutor quiera evaluar comprensión de materias teóricas
- En modo parcial para materias sin código
- Cuando se diga "caso de análisis", "ejercicio de eco", "ejercicio de gestión"

## Filosofía
- **Aplicar, no repetir** — saber una teoría es poder usarla, no recitarla
- **Gráficos como lenguaje** — en Economía, si no lo podés graficar no lo entendés
- **Casos reales > definiciones** — preferir situaciones concretas sobre abstracciones
- **Justificar siempre** — "¿por qué elegiste esa respuesta?" es obligatorio
- **Conectar teorías** — un buen ejercicio cruza dos o más conceptos

## 5 Niveles de Progresión

### Nivel 1: Identificar
El estudiante reconoce conceptos en una situación dada.

Formatos:
- "¿Qué concepto económico aplica en esta situación?"
- "¿Qué teoría de motivación describe este caso?"
- "Identificá oferta, demanda y equilibrio en este mercado"
- "¿Qué tipo de liderazgo muestra este gerente?"

### Nivel 2: Clasificar y Comparar
El estudiante diferencia entre conceptos similares.

Formatos:
- "¿Esto es un desplazamiento de la curva o un movimiento sobre la curva?"
- "¿Es bien elástico o inelástico? Justificá"
- "Maslow vs Herzberg: ¿cuál explica mejor esta situación?"
- "Competencia perfecta vs monopolio: clasificá este mercado"

### Nivel 3: Analizar (el core)
El estudiante descompone una situación y explica causas y efectos.

Formatos Economía:
- Dado un evento → "¿Qué pasa con precio y cantidad de equilibrio? Graficá"
- "El gobierno pone un impuesto de X. ¿Quién absorbe más? ¿Por qué?"
- "Subió el precio del bien complementario. ¿Qué pasa con la demanda?"
- "¿Qué efecto tiene una expansión monetaria sobre inflación y desempleo?"

Formatos Gestión:
- "La empresa tiene alta rotación. Diagnosticá usando teoría de motivación"
- "Hay conflicto entre dos áreas. ¿Qué estilo de negociación recomendás?"
- "El equipo no rinde. ¿Es un problema de liderazgo, cultura o estructura?"
- "Análisis FODA de esta organización"

### Nivel 4: Evaluar
El estudiante juzga la calidad de una decisión o propuesta.

Formatos:
- "El gerente decidió X. ¿Fue buena decisión? ¿Qué alternativa había?"
- "Este gráfico muestra que el mercado está en equilibrio. ¿Estás de acuerdo?"
- "La empresa implementó un programa de bienestar. ¿Va a reducir rotación? ¿Por qué?"
- "Dos economistas proponen soluciones opuestas. ¿Cuál es más robusta?"

### Nivel 5: Diseñar / Proponer
El estudiante crea una solución o estrategia completa.

Formatos:
- "Diseñá una política fiscal para esta situación económica"
- "Proponé un plan de motivación para este equipo usando 2 teorías"
- "Modelá este mercado: identificá oferta, demanda, factores y graficá"
- "Diseñá la estructura organizacional para esta startup"

## Sistema de Hints (análogo a coding-exercises)

| Nivel de hint | Tipo | Ejemplo |
|---|---|---|
| 1 | Pregunta socrática | "¿Qué variable se mueve primero?" |
| 2 | Dirección general | "Pensá en la elasticidad" |
| 3 | Pista específica | "La demanda es inelástica porque es un bien necesario" |
| 4 | Framework parcial | "Usá Herzberg: factores higiénicos vs motivadores" |
| 5 | Solución guiada | Solo si ya intentó 3+ veces |

## Ejercicios por Materia

### Economía
| Tema | Tipos de ejercicio |
|---|---|
| Oferta/Demanda | Graficar desplazamientos, calcular equilibrio, efecto de impuestos |
| Elasticidad | Calcular, interpretar, predecir quién absorbe impuesto |
| Mercados | Clasificar estructura, comparar competencia vs monopolio |
| PIB/Inflación | Calcular, interpretar variaciones, relación con desempleo |
| Política fiscal/monetaria | Predecir efectos, diseñar políticas, tradeoffs |

### Gestión de Personas
| Tema | Tipos de ejercicio |
|---|---|
| Motivación | Aplicar Maslow/Herzberg/McGregor a casos, comparar teorías |
| Liderazgo | Identificar estilo, recomendar cambio, liderazgo situacional |
| Conflicto | Diagnosticar, elegir estrategia de negociación, mediar |
| Cultura organizacional | Diagnosticar tipo, proponer cambios, FODA |
| Estructura organizacional | Diseñar, comparar centralizado vs descentralizado |
| Comunicación | Identificar barreras, proponer mejoras |

## Corrección de Ejercicios

Al corregir, evaluar:
1. **Precisión conceptual** — ¿usó la teoría correcta?
2. **Justificación** — ¿explicó el por qué?
3. **Gráficos** (Eco) — ¿ejes correctos? ¿desplazamiento correcto?
4. **Conexiones** — ¿conectó con otros conceptos?
5. **Propuesta** — ¿es realista y fundamentada?

## Anti-patterns
- NO aceptar "porque sí" como justificación
- NO pedir definiciones textuales — preferir aplicación
- NO hacer ejercicios sin conexión con las notas de clase reales
- NO saltar niveles si el estudiante no demuestra dominio del anterior
- NO usar solo MC — variar entre caso, gráfico, diseño y comparación
